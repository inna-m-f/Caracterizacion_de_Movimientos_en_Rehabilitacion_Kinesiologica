# GUI de KinePose

Esta carpeta contiene los mockups de la interfaz gráfica de KinePose. El
**Panel Clínico** está pensado para que el kinesiólogo pueda administrar
pacientes, cargar sesiones y revisar la evolución de sus movimientos.

## Panel Clínico

El panel se divide en las siguientes partes:

- **Barra lateral:** muestra la identidad de KinePose y permite navegar entre
  Pacientes, Nueva sesión y Comparador. En la parte inferior identifica al
  profesional y al centro de rehabilitación.
- **Pacientes:** incluye un buscador por nombre, RUT o diagnóstico, una tabla
  con el historial de pacientes y un detalle individual con sus sesiones,
  evolución y gráfico de progreso.
- **Nueva sesión:** permite seleccionar al paciente y el ejercicio, cargar un
  video y visualizar el avance del análisis. También incorpora el protocolo
  de captura para verificar las condiciones del video.
- **Comparador de sesiones:** permite seleccionar dos sesiones del mismo
  paciente, visualizarlas lado a lado o superpuestas y revisar métricas como
  flexión de rodilla, cadera y tronco. Además, permite agregar observaciones
  clínicas y exportar un informe.
