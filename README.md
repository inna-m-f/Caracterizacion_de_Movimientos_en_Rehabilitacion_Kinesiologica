# Caracterización de movimientos en rehabilitación kinesiológica

> Proyecto de Procesamiento Digital de Imágenes

Este es el repositorio correspondiente a nuestro proyecto para la asignatura de Procesamiento Digital de Imágenes, las cuales consta de una
caracterización de movimientos en rehabilitación kinesiológica.

### Objetivo:

Nuestro objetivo con este proyecto es lograr dar apoyo al proceso de rehabilitación de los pacientes de los kinesiólogos permitiéndoles 
a ambas partes lograr sostener un control sobre la evolución de la recuperación del paciente, provocándole al paciente una respuesta tangible sobre su propio progreso y permitiendo que de forma consciente continúe con su rehabilitación. Todo esto se realizará mediante un programa con visión de computador y nuestros conocimientos adquiridos en el ramo de procesamiento digital de imágenes junto con otras aplicaciones de conocimientos vistos a lo largo de nuestra trayectoria estudiantil como para el diseño de las interfaces del usuario.
